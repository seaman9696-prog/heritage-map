# Notion「世界遺産データベース」の空のページを埋める作業

前のセッションからの引き継ぎ。ユーザーの了承済みの作業（Notionへの書き込みOK・1件ごとの確認は不要）。

## 対象

- Notionのデータソース: `collection://34072489-2ded-8079-a382-000ba79eebcb`（親ページ「世界遺産データベース」）
- 2026年10月3〜4日にまとめて追加された、本文が「📝 基本データ」の1行だけ・キーワードとテーマが空のページ 611件（`ids.txt`、ページIDの末尾32文字）
- `rows.json`: 各ページの遺産名・英語名・UNESCO番号・登録年・登録基準・分類・国（`heritage_map.json` から抜き出したもの）
- `done.txt`: 書き込み済みのページID。書き込んだら1行ずつ追記して、このブランチにコミットする

## 情報源のルール

- 情報源は**日本語版Wikipedia**だけ。UNESCOのサイトは自動アクセスを403で拒否するので使わない（ブラウザのふりをして回り込まない）
- `wiki/<ページID>.json` に記事本文（`wiki.text`）が集めてある。`wiki` が null の遺産は**記事なし → 書かずに飛ばす**（ユーザーの決定）
- 記事集めの続き: `python3 -I notion_fill/wiki_all.py notion_fill/rows.json notion_fill/wiki`（保存済みは飛ばす。並列なし。Wikipediaの429には待って再試行）。連絡先入りのUser-Agentを付けている
- 次に書く遺産と記事本文を見る: `python3 -I notion_fill/next.py notion_fill 3`
- 記事が遺産そのものではなく都市・川などの記事のときは、遺産に関係する部分だけ使い、出典の行にその旨を書く
- Wikipediaにない内容をAIの知識で補ったときは、出典の行に「※…はAIの知識で補ったもので、未確認です」と具体的に書く。登録基準ごとの説明をAIが本文から割り当てたときも、その旨を書く
- Wikipediaの明らかな誤り（単位の間違いなど）は使わない

## 書き方（1件につき2回の書き込み）

1. `notion-update-page` の `insert_content`（`position: end`）で、既存の「📝 基本データ」の後ろに本文を足す。既存の行は消さない
2. `notion-update-page` の `update_properties` で `キーワード`（「、」区切りのテキスト）と `テーマ`（下の選択肢から。新しい選択肢は作らない）を入れる
3. `1級充実化済み` は触らない

テーマの選択肢: 文化的景観, 危機遺産, 宗教建築, キリスト教, トランスバウンダリー, 考古遺跡, 産業遺産, 歴史都市, 自然景観, 古代文明, 近代建築, シリアル・ノミネーション, 民主主義遺産, 森林, 宮殿・庭園, 生態系・生物多様性, 先史文化, 地形・地質

本文のひな形（既存の富士山・イグアスのページに合わせた形）:

```
## ⭐ 評価されたポイント（登録基準の詳細解説）

**登録基準(…)**：（場所・概要・登録年）

（基準ごとの説明。根拠が本文にあるときだけ）

- (…) 基準の短い説明

---

## 🎯 重要キーワード

- **登録年・登録基準（国）**
- （5〜6項目）

---

## 🏛️ 歴史的背景と詳細ポイント

（2〜3段落）

---

## 📝 学習メモ

---

出典：日本語版Wikipedia「記事名」（2026年11月取得）。※（AIで補った部分があれば具体的に）
```

「試験頻出」とは書かない（頻出かどうかは確かめていないため。見出しは「重要キーワード」）。

## 進め方

- 確認なしでどんどん進めてよい（ユーザーの指示）。区切りごとに `done.txt` をコミットしてこのブランチに push する
- 終わったら、書いた件数・記事がなく飛ばした件数（一覧）を報告する
- アルスランテペの遺丘はAIの知識だけで書いてあるが、ユーザーの判断でそのままにする
